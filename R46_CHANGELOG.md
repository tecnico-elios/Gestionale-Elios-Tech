# R46

## Navigazione coerente
Le voci principali della sidebar sono ora vere radici di sezione. Ogni click forza il reset dello stato locale della pagina, anche quando si clicca una voce che punta allo stesso URL già aperto.

Esempio: se è aperta la scheda di un cliente e si clicca `Clienti / Ordini`, viene riaperta la lista iniziale; stesso comportamento per tutte le altre sezioni.
